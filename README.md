# Dickson Onyango — Developer Portfolio

A responsive dark-themed portfolio built with plain HTML, CSS and JavaScript for GitHub Pages.

## Before publishing
1. Replace `assets/profile-placeholder.svg` with your own photo. The simplest option is to upload a JPG named `profile.jpg` into `assets/`.
2. In `index.html`, change the image source from `assets/profile-placeholder.svg` to `assets/profile.jpg`.
3. Replace `YOUR_EMAIL@example.com` with your real email address.
4. Check the LinkedIn link and update it to your profile URL (or remove it if you do not use LinkedIn).
5. Review the skills and project description so they accurately reflect your current work.

## Publish with GitHub Pages
1. Create a **public** GitHub repository named exactly `YOUR-USERNAME.github.io`.
2. Upload all files and folders from this package to the repository root. Keep `index.html`, `style.css`, and `script.js` in the root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for deployment. Your site URL will be `https://YOUR-USERNAME.github.io/`.
